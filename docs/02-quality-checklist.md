# 质量检查清单

这个清单用来判断一次批量 Excel 补全任务能不能交付。

## 输入检查

- Excel 至少有公司名称列。
- 如果有统一社会信用代码、地区，读取时保留。
- 空公司名跳过，不生成无意义任务。
- 原始字段导出时能带回结果表。

## 运行检查

- 浏览器 profile 不提交到仓库。
- 运行日志写到 `logs/`。
- 进度库写到 `data/`。
- 结果文件写到 `outputs/`。
- 中断后再次运行不会重复采集已成功记录。

## 结果检查

- 每一行都有明确状态。
- 成功记录包含年份和员工数。
- 未匹配、多候选、无员工数、权限不足、验证提示等情况分开记录。
- 失败记录可以单独导出，用于人工复核或补跑。

## 发布前检查

- `python -m pytest -q` 通过。
- `samples/` 里只放脱敏样例。
- `.gitignore` 覆盖 `data/`、`outputs/`、`logs/`、`browser_profiles/`、`.env`。
- README 中不出现真实客户文件名、账号、cookie、截图或运行证据。
