# 合规和脱敏边界

这个仓库是一次真实项目的脱敏整理版，只用于展示本地浏览器自动化、Excel 交付和断点续跑的工程方法。

## 公开仓库可以放什么

- 脱敏样例 Excel。
- 输入输出字段结构。
- CLI 和测试代码。
- 进度保存、异常分类、导出模板。
- 项目复盘和质量清单。

## 公开仓库不要放什么

- 客户原始 Excel。
- 真实导出结果。
- 账号、密码、cookie、token。
- 浏览器 profile。
- 验证码截图。
- 运行日志和页面留证。
- 可以直接用于高频批量请求的配置。

## 使用边界

使用者需要自己确认目标网站的服务条款、账号权限和数据使用范围。

这个项目保留人工登录和人工处理异常的流程，是为了让本地任务可控、可暂停、可复核，不是为了绕过访问限制。
